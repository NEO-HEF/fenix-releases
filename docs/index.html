Instalace aplikací — automatická aktualizace přes Windows App Installer

Návod k instalaci

Doporučeno ⭐ Hromadný instalátor

Nejjednodušší způsob, jak nainstalovat Fenix. Jedna aplikace, která sama najde dostupné moduly (podle zvolené verze Fenixu a kanálu) a umožní nainstalovat jeden, vybrané nebo všechny moduly najednou. Nainstalované moduly si pak dál drží vlastní automatickou aktualizaci. Doporučený první krok pro nové stanice.

Instalovat hromadný instalátor Stáhnout .appinstaller

Tlačítko Instalovat používá protokol ms-appinstaller: — pokud nereaguje, je protokol vypnutý (viz Povolení protokolu níže).

Alternativa Stáhnout .appinstaller funguje, ale dvojklik na stažený soubor spustí instalaci jen tehdy, když je přípona .appinstaller přiřazená k aplikaci Instalátor aplikací (App Installer / Instalační služba aplikací). Pokud dvojklik hlásí chybu, otevřete soubor ručně: pravým tlačítkem na stažený soubor → Otevřít v programu (Open with) → Zvolit jinou aplikaci → Instalátor aplikací; volitelně zaškrtněte Vždy používat tuto aplikaci pro .appinstaller. Podrobný postup viz Dvojklik hlásí chybu níže.

Verze Fenixu a kanály

Nejprve zvolte záložku verze Fenixu (např. Fenix 10.01), pak uvnitř kanál (Alpha / Beta / Prod). Každá verze Fenixu je samostatná aplikace s vlastní identitou — instaluje a aktualizuje se nezávisle na ostatních verzích.

Akce v tabulce kanálu

  • Instalovat — spustí Windows App Installer přímo z prohlížeče (vyžaduje povolený protokol, viz níže).
  • Stáhnout — stáhne soubor .appinstaller; po stažení ho otevřete dvojklikem. Tato cesta funguje vždy.
  • PowerShell — zkopíruje do schránky příkaz pro instalaci z příkazové řádky (pro pokročilé / hromadné nasazení).

Co se stane po dvojkliku na soubor .appinstaller

  1. Otevře se Windows App Installer s informacemi o aplikaci (název, vydavatel Asseco Solutions a.s., verze).
  2. Kliknete na Instalovat (případně Aktualizovat, pokud už máte starší verzi téže linie).
  3. App Installer stáhne balík .msix z GitHubu a nainstaluje ho.
  4. Aplikace se objeví v nabídce Start. Při dalších spuštěních se sama aktualizuje, pokud je v rámci téže verze Fenixu k dispozici novější build.

Dvojklik hlásí chybu — přípona .appinstaller není přiřazená

Příznak: dvojklik na stažený soubor (např. RZP.appinstaller) skončí nepopisnou chybou typu „Aplikaci RZP nelze otevřít". Windows neví, že soubor má otevřít App Installer — přípona .appinstaller u vás zatím není přiřazená k Instalační službě aplikací (App Installer). Dvojklik proto nefunguje.

Řešení — soubor otevřete ručně přes App Installer:

  1. Klikněte na stažený soubor pravým tlačítkem → Otevřít v programu (angl. Open with) → Zvolit jinou aplikaci.
  2. Vyberte App Installer (Instalační služba aplikací). Pokud není vidět, rozbalte Více aplikací.
  3. Volitelně zaškrtněte Vždy používat tuto aplikaci pro otevírání souborů .appinstaller — od té chvíle bude dvojklik fungovat napřímo.
  4. Potvrďte a v okně App Installeru klikněte Instalovat.

Tip: pokud chcete instalaci bez řešení asociací úplně obejít, použijte tlačítko PS instalace v tabulce a vložte příkaz do PowerShellu.

Přechod mezi kanály (v rámci jedné verze Fenixu)

V rámci jedné verze Fenixu sdílejí kanály Alpha / Beta / Prod stejnou identitu aplikace, takže se na jednom počítači vzájemně vylučují — nainstalovaná je vždy jen jedna z nich. Přechod na jiný kanál znamená nahrazení stávající instalace:

  1. Odinstalujte aktuální verzi (viz Odinstalace níže).
  2. Nainstalujte modul z příslušného kanálu (sub-záložky Alpha / Beta / Prod uvnitř téže verze).

Přechod na kanál s vyšším buildem proběhne i prostou instalací bez odinstalace (chová se jako aktualizace); přechod na nižší build (např. z alpha zpět na prod) vyžaduje nejdřív odinstalaci.

Přechod mezi verzemi Fenixu (10.01 → 10.11)

Různé verze Fenixu (10.01, 10.11, …) jsou samostatné aplikace s odlišnou identitou. Přechod mezi nimi neproběhne automaticky — vyžaduje migraci databázového schématu a reinstalaci všech modulů. Aplikace se proto nikdy sama neupgraduje z 10.01 na 10.11; obě mohou být i nainstalované vedle sebe. Přechod koordinujte podle pokynů dodavatele (migrace dat) — teprve poté odinstalujte starou verzi a nainstalujte novou.

Odinstalace

Aplikaci lze odinstalovat dvěma způsoby:

  • Nabídka Start — pravým tlačítkem na dlaždici aplikace → Odinstalovat.
  • Nastavení → Aplikace → Nainstalované aplikace → najít modul → Odinstalovat.
  • PowerShell — tlačítko PS odinstalace v tabulce zkopíruje příkaz konkrétní verze, např.: 
    Get-AppxPackage Asseco.Fenix.RZP.v10-1 | Remove-AppxPackage
    (Identita nese verzi Fenixu — .v10-1 = linie 10.01, .v10-11 = linie 10.11.)

Odinstalace odebere aplikaci i s jejím lokálním úložištěm (nastavení, cache). Sdílená data v databázi Fenix zůstávají nedotčena.

Povolení protokolu „Instalovat" (ms-appinstaller)

Tlačítko Instalovat používá protokol ms-appinstaller:, který Microsoft z bezpečnostních důvodů od roku 2023 ve výchozím stavu vypíná. Na firemních počítačích ho povoluje IT skupinovou politikou (GPO):

Pro IT: povolit politiku Enable App Installer ms-appinstaller protocol (App Installer ADMX), registry HKLM\Software\Policies\Microsoft\Windows\AppInstaller → EnableMSAppInstallerProtocol = 1.

Pokud protokol není povolen, tlačítko Instalovat nereaguje — použijte Stáhnout a soubor otevřete dvojklikem (funguje vždy, bez jakéhokoli nastavení).

Systémové požadavky a závislosti

Tato sekce platí společně pro všechny aktuálně podporované verze Fenixu. Pokud se požadavky některé verze začnou lišit, doplní se zde samostatná pod-sekce pro danou verzi.

Operační systém

  • Windows 10 verze 2004 (build 19041) nebo novější, případně Windows 11.

Runtime

  • .NET 10 Desktop Runtime. Pokud runtime není na počítači nainstalovaný, aplikace si při startu řekne o jeho instalaci a nabídne stažení příslušného instalačního balíčku. Stažený balíček najdete ve složce Stažené soubory; stačí ho spustit (vyžaduje zvýšená oprávnění) a po dokončení instalace znovu spustit RZP.

Crystal Reports runtime

  • Crystal Reports runtime je potřeba pro tiskové výstupy, obecně pro sestavy. Instalační balíček je možné stáhnout z adresy https://origin-az.softwaredownloads.sap.com/public/file/0025000000164822025.

Databáze a další závislosti

  • Pro práci s databázovými a Office soubory musí být na stanici nainstalovaný alespoň jeden z OLE DB providerů Microsoft.ACE.OLEDB.16.0 nebo Microsoft.ACE.OLEDB.12.0.
  • Doporučeno: použít novější Microsoft.ACE.OLEDB.16.0, ideálně přes Microsoft 365 Access Runtime. Pro aktuální balíky RZP instalujte 64bitovou variantu (x64). Oficiální stránka ke stažení: Microsoft 365 Access Runtime. Přímé české instalační odkazy: x64, x86.
  • Alternativně lze použít Microsoft Access Database Engine 2016 Redistributable z oficiálního Microsoft Download Center: https://www.microsoft.com/en-us/download/details.aspx?id=54920. Microsoft u této starší redistribuce uvádí ukončenou podporu a jako doporučenou náhradu odkazuje na Microsoft 365 Access Runtime.
  • Microsoft.ACE.OLEDB.12.0 berte jako kompatibilní fallback pro stanice, kde už je tento provider k dispozici. Pro nové instalace preferujte Microsoft.ACE.OLEDB.16.0.

Podpis a důvěryhodnost

  • Aplikace jsou podepsané veřejně důvěryhodným EV certifikátem Asseco Solutions a.s. (vydavatel DigiCert) — instalace nevyžaduje ruční důvěřování certifikátu.

Síť
